# Adhan Clock

A prayer-time clock for a wall-mounted tablet, inspired by the Masjidal Athan
Clock. Static web app (Vite + Preact + TypeScript); prayer times are computed
on the device with [adhan-js](https://github.com/batoulapps/adhan-js), settings
live in the browser.

Live: https://adhan-clock-fs.web.app

Work in progress.
